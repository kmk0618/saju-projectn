- `node scripts/verify-child-midlayer.mjs`, `node scripts/verify-couple-midlayer.mjs`: 통과.
- TypeScript 및 ESLint 검사: 통과.
- `npm run build`: 운영 빌드 성공. `/api/generate` runtime 재수출 경고도 수정.
- `npm audit --omit=dev`: 취약점 0건. 의존성 데이터베이스 조회 시점 기준.

## 남아 있는 운영 확인

1. **배포:** 현재 변경은 로컬이다. 운영 서버의 예전 공개 파일·CDN 캐시는 배포 후 다시 확인해야 한다. 과거 다운로드나 과거 배포 URL까지 삭제한 것은 아니다.
2. **운영 DB 권한:** RLS·Storage 비공개 여부·함수 실행권한은 이전 점검에서 조회가 제한된 항목이다. 이번 로컬 작업으로 검증 완료했다고 판단하지 않는다. 새 API가 소유권을 검사하더라도 다른 DB 접근 경로의 RLS는 별도로 필요하다.
3. **전체 구매 흐름:** 실제 PG 테스트 결제 → 네 상품 전체 AI 생성 → 다운로드, 인증된 이메일의 실제 비회원 주문 복구, 다중 서버 lease 동작은 스테이징 통합 검증이 필요하다. 실제 결제·환불은 이번에 실행하지 않았다.
4. **미완성 구버전 리포트:** 완료된 기존 PDF는 그대로 열 수 있다. PDF 없는 미완성 구버전은 본문을 보존하고 `LEGACY_REPORT_REVIEW_REQUIRED`로 자동 덮어쓰기를 막는다. 운영 데이터와 DB 제약을 확인한 뒤 별도 리비전으로 복구해야 한다. 새 버전으로 자동 마이그레이션하는 기능은 구현하지 않았다.
5. **비회원 복구 범위:** 동일한 이메일의 인증된 로그인 계정이 필요하다. 결제 이메일 오입력, 다른 이메일의 소셜 로그인, 이메일 자동 발송·SMTP 설정은 별도 운영 대응 대상이다. 링크 만료·회전 정책도 이번에 변경하지 않았다.
6. **후기·정책 사실:** 기존 정적 후기의 실제 구매 증빙·동의, 할인 기준가, 개인정보 보관·국외 처리 등은 사용자 운영 사실이 필요해 임의 변경하지 않았다.
7. **해석 품질:** 역사적 표준시·해외 출생·절기 경계 기준값의 전문 검증과 네 상품 실제 생성본 전체 검수는 별도다. 무료 답변은 AI 심층 해석이 아니라 계산값과 질문 키워드를 쓰는 간단한 규칙형 해석이다.
8. **기기별 결제:** 실제 iOS Safari·Android·카카오 인앱 결제 복귀와 PDF 저장은 미검증이다.
